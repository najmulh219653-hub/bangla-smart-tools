# 🌟 Bangla Smart Tools

Bangla Smart Tools is a multilingual AI-powered Telegram bot built with Node.js, Google Gemini Interactions API and Math.js.

## ✨ Features

- ✍️ AI Auto Post Writer
- 🔵 Facebook Content
- 🎵 TikTok Captions
- ▶️ YouTube Titles and Descriptions
- 📸 Instagram Captions
- ✈️ Telegram Posts
- 𝕏 X / Twitter Posts
- 💼 LinkedIn Posts
- 🎬 Video Content Generator
- 🧮 Smart Calculator
- 🌐 Bengali Translator
- 🔢 Bengali and English Number Converter
- 📚 Mathematics Formulas
- ℹ️ About Section

## 🛠️ Technologies

- Node.js 22+
- Telegram Bot API
- Google GenAI SDK
- Gemini Interactions API
- Math.js
- Express.js

## 🔐 Environment Variables

Set these variables in your hosting dashboard:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

GEMINI_API_KEY=YOUR_GEMINI_API_KEY

GEMINI_MODEL=gemini-4-hydrogen

PORT=3000

Never publish your API keys or bot token in GitHub.

## 🚀 Installation

Install dependencies:

npm install

Run the bot:

npm start

## 📌 About

Bangla Smart Tools brings useful digital tools into one Telegram bot. It helps users create social media content, generate video ideas, translate text, and calculate mathematical expressions.

Built to make digital tasks easier and more accessible.

## ⚠️ Notes

- AI features require a valid Gemini API key.
- API usage is subject to Google's model availability and usage limits.
- Translation uses the MyMemory service.
- The bot generates content but does not automatically publish it to social media.
